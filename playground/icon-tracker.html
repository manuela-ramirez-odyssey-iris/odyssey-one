Lucide Icon Tracker

Icons to add manually to the Design System - MCP Figma library via the official Lucide plugin. Updated whenever a normalization touches a new icon. Gray cards = already in the library; yellow cards = pending manual add.

How to add an icon to Figma

  1. Open Design System - MCP in Figma. Place the icon inside the right frame:
    • md (16px) icons → Lucide Icons md (node 230:1054)
    • lg (20px) icons → Lucide Icons lg (node 366:619)
  2. Run Plugins → Lucide. Search the plugin search name shown on the card (kebab-case) and insert.
  3. Resize to the target size (16 for md, 20 for lg).
  4. Change stroke width to match the card. Lucide defaults to 2; Odyssey overrides to 2.25 at md and 2 at lg. Bind it to the matching variable (Stroke / md or Stroke / lg) from the Icon collection.
  5. Right-click → Create component (Cmd+Opt+K). The default name is fine — Claude renames it.
  6. Tell Claude "TriangleAlert added" (or whichever icons). Claude will:
    • Rename the component to lucide/md/TriangleAlert or lucide/lg/TriangleAlert (PascalCase, matching lucide-react for Code Connect later)
    • Mark the tracker card as done

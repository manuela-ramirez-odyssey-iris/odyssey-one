# 30 — Ideas

Speculative content — your commentary, brainstorms, hypotheses, drafts. **Not facts. Not decisions.**

## Distinction from `10-domains/` and `40-decisions/`

- **`10-domains/<domain>/`** = canonical information (domain analysis, grooming, etc.)
- **`40-decisions/`** = "we decided X, because Y"
- **`30-ideas/`** = "what if we…" / "I was thinking…" / "this might be a better approach"

Ideas can graduate to decisions (moved to `40-decisions/`), inform domain docs (referenced from `10-domains/`), or be archived (moved to `99-archive/`).

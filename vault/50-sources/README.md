# 50 — External Sources

Raw inputs from outside Odyssey-One development that don't attach to a specific product domain. Things like:

- Industry reports
- Regulatory documents
- Third-party API specs
- Recordings of cross-domain meetings (general team syncs, not domain grooming)

Domain-attached sources (Shipments grooming, Shipments PPTX, brand marketing PDF) live next to their domain — under `10-domains/<domain>/grooming/`, `10-domains/<domain>/powerpoints/`, or `20-cross-cutting/<topic>/`.
